[SPOILER=Рекомендуемый сценарий использования]
1. Отключите «системную» АПЧ (AFR) (см. вопрос «Нужно ли включать "системную" АПЧ (AFR) при использовании AFRd?» в FAQ).

2. Те приложения, которые имеют встроенную АПЧ (AFR), и работа которых вас полностью устраивает, добавьте в настройках в список «Плееры, которым AFR мешает» (см. вопрос «Нужно ли включать АПЧ (AFR) в приложениях, в которых эта функция есть, при использовании AFRd?» в FAQ). На Android 10+ в этом списке по умолчанию уже стоит OTT Navigator — он сам управляет частотой; штатный YouTube не исключён.
Если работа встроенного АПЧ конкретного приложения вызывает у вас сомнения, отключите эту опцию в его настройках и понаблюдайте, как будет справляться с задачей AFRd2. Окончательное решение о том, какой именно механизм лучше использовать, сможете принять позднее.

3. Ускорение переключения режима (обычно 10–20 секунд):
— Если плеер отдаёт подсказку частоты (frame_rate_hint), проверьте, что в «Настройках» → «Тонкая настройка Android 11+» включено «Доверять подсказке плеера» (по умолчанию включено). Тогда AFRd2 берёт частоту из подсказки, а собственный замер её проверяет; при расхождении по группе частот (24/25, 30/60) режим будет исправлен.
— Если подсказки нет, включите «Быстрое решение по заявленной частоте» («Настройки» → «Тонкая настройка Android 11+»): режим применится через 2–4 секунды по частоте, которую заявил декодер, — так же поступает и штатная системная АПЧ. Решение предварительное: собственный замер продолжает работать, и если заявленная частота окажется другой по группе частот (24/25, 30/60), режим будет исправлен — возможны второй «щелчок» и несколько секунд неверного режима. На Android 10/11 ключ по умолчанию включён, на Android 12–14 выключен (подробнее — в FAQ, вопрос «Можно ли переключать частоту быстрее, чем за 10–20 секунд?»).

4. Если смотрите IPTV и при серфинге по каналам экран мигает (пустой канал возвращает 60 Гц), на Android 11 и выше поставьте «Задержка остановки, мс» = 10000–12000 («Настройки» → «Тонкая настройка Android 11+»). Канал, который открывается 5–10 секунд, успевает появиться внутри окна, и режим не возвращается; ожидание прерывается сразу, как только поток появился, поэтому переключение каналов не замедляется. Цена: после настоящего конца видео режим держится ещё столько же. Подробности — в ЧАВО, вопрос «Почему при переключении каналов IPTV экран мигает?».
