## Как продолжить

1. `cd ~/AI/afrd2 && git log --oneline -8` — что уже сделано.
2. `sh tests/run_tests.sh` — должны быть зелёными (21 C + 7 Java).
3. Открыть `docs/audit/report-2026-11.md`, раздел «Проход 2»: что осталось незакрытым.
4. Стенды: `adb devices` — `.50`/`.48`, с 03.11 в сети и `.42` (VONTAR X4, ATV11, вендорный
   путь). Перед прогонами включить `log.enable=1`, править ini **после** запуска приложения
   (иначе оно перезапишет файл из prefs). Ручной запуск демоном на `.42` сверяет путь
   `vendor.disp.cli`: если он указывает на несуществующий файл, `platform_detect` уходит в
   ATV14 — брать путь из кэша приложения (`.../cache/afrd-disp.sh`).
5. `.48`: демон не получает vdec-uevent (клип играет, «Starting framerate detection» нет) —
   начать с этого, иначе legacy-путь там не проверить.

   Сделано также: `Control` (вывод/код su в logcat), `Burst` (разбор `too-soon`), `daemon_pid`
   (сверка `/proc`).
